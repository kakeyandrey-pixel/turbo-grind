# TURBO GRIND — Telegram Mini App (первый прототип)

## Что уже работает
- прогресс до 150 игр;
- добавление сразу нескольких игр;
- статистика за сегодня и последние 7 дней;
- история записей;
- отмена последнего добавления;
- адаптивный тёмно-красный интерфейс;
- подключение Telegram Web Apps SDK.

## Важно
Это frontend-прототип. Пока данные хранятся в localStorage браузера/Telegram на конкретном устройстве.
Для синхронизации между устройствами и надёжного хранения понадобится backend и база данных.
При подключении backend нужно проверять `Telegram.WebApp.initData` на сервере. Не доверяйте `initDataUnsafe` и никогда не помещайте токен бота в frontend.

## Запуск для проверки
Откройте `index.html` в браузере. Вне Telegram приложение работает в демо-режиме.
Для подключения в Telegram потребуется разместить сайт на HTTPS-хостинге и указать URL Mini App через @BotFather.
